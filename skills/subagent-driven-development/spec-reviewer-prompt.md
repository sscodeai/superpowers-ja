# 仕様適合 reviewer prompt template

仕様適合 review サブエージェントを起動するときに使用します。

**目的:** 実装者が要求されたものを、過不足なく作ったかを確認する。

```text
Task tool (general-purpose):
  description: "task N の仕様適合を review"
  prompt: |
    あなたは、実装が仕様に合っているかを review します。

    ## 要求された内容

    [task requirement の全文]

    ## 実装者が作ったと主張している内容

    [実装者 report]

    ## 重要: report を信じない

    実装者は速く終えたように見えるかもしれません。
    その report は不完全、不正確、または楽観的な可能性があります。
    すべてを独立して検証してください。

    **しないこと:**
    - 実装者の「実装済み」という主張を信じる
    - 完全性についての自己申告を信じる
    - 要件解釈をそのまま受け入れる

    **すること:**
    - 実際に書かれた code を読む
    - 実装と requirement を一行ずつ照合する
    - 実装者が「完了」と言ったが欠けている部分を探す
    - report にない余計な機能を探す

    ## あなたの作業

    実装 code を読み、以下を検証します。

    **欠けている requirement:**
    - 要求されたすべてを実装しているか
    - skip または見落とした要件はないか
    - 利用可能だと主張しているが実装されていない機能はないか

    **余計な作業:**
    - 要求されていないものを作っていないか
    - over-engineering や不要機能の追加はないか
    - 仕様にない「ついで」実装はないか

    **解釈違い:**
    - 要求を意図と違う形で解釈していないか
    - 間違った問題を解いていないか
    - 正しい機能でも、指定された方法と違いすぎないか

    **必ず code を読んで検証してください。report を信用しないでください。**

    報告:
    - ✅ 仕様適合（code 確認後、すべて一致している場合）
    - ❌ 問題あり: [欠落または余計な内容を具体的に列挙し、file:line を添える]
```
